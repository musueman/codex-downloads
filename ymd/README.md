# ymd asset package

Minimal LunaTalk asset package for `너는 내 운명이야`.

- Backgrounds: `bg/b01.png` ... `bg/b10.png`
- Characters: `ch/c01_e01.png` style names
- Character intro cards: `intro/c01.webp` ... `intro/c08.webp`
- Scene selector: `b={background}, c={character}, e={emotion}`
- Full mapping: `asset-map.json`
